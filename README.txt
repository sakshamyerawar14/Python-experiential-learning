SMART BANKING SIMULATOR

How to run:
1. Open a terminal in this folder.
2. Run: python banking.py

The program will automatically create:
- accounts.json
- bank_activity.log

Features:
- Create account
- PIN verification with SHA-256 hashing
- Deposit
- Withdraw
- Transfer
- Transaction history
- Activity logging
- Persistent JSON storage

Note: This is an educational simulator, not production banking software.
